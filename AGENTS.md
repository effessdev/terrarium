# AGENTS.md

## Project Rules

- Keep the project small, modular, and easy to maintain.
- Avoid unnecessary dependencies.
- Maintain the 1280×720 window size.
- 60 FPS target for PCs with only 8GB of RAM and 3 GHz dual-core processor (only iGPU).
- Update `TODO.md` whenever work is completed.
- Work incrementally: implement and test one small change at a time.
- Do not rewrite working code without a clear reason.
- Keep modules focused and avoid large files.
- Each part of the project must be independent, so multiple people can work on it at the same time.
